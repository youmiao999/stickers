# stickers · 表情包

一个能搜、能筛、点一下就复制的表情包网页。打开 `index.html` 就能用。

- **搜索**：搜图上的字、心情、拼音文件名都行，比如 `贴贴`、`凶我`、`哈士奇`、`tietie`；空格隔开多个词 = 同时满足
- **筛选**：按心情（黏人 / 撒娇 / 爱你 / 委屈 / 凶凶 / 认错 / 搞怪）和主角（狗 / 猫 / 小人 / 其他）
- **复制**：点开一张 → 复制图片（直接粘进聊天框）、复制链接、复制 Markdown、下载；电脑上鼠标移到图上有快捷复制按钮
- **最近用过**：复制过的会记在这台设备上，方便下次直接找
- **随便来一张**、键盘 `/` 搜索、`← →` 切换、`C` 复制、`Esc` 关闭
- 链接后面加 `#文件名` 直接打开那张，比如 `index.html#tietie`

## 加新表情包

1. 图片放在仓库根目录，文件名用拼音（比如 `tietie.jpeg`）
2. 在 `stickers.js` 里加一行：

```js
{ file: "tietie.jpeg", text: "贴贴 贴贴", mood: ["黏人"], who: "猫", kw: "蹭 小猫" },
```

忘了加也没事：网页会从 GitHub 找出没登记的新图，先用文件名显示，标着「新」。

## 上线（GitHub Pages）

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录 `/ (root)`，保存。
过一两分钟就能在 `https://youmiao999.github.io/stickers/` 打开。
